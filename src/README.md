# Python Source

This folder contains the Python script version of the NYC Airbnb exploratory data analysis.

## File

`nyc_airbnb_eda.py`

The script covers the main analysis workflow, including:

- loading the Airbnb dataset
- inspecting dataset structure and descriptive statistics
- cleaning column names
- removing duplicate records
- identifying and handling missing values
- correcting inconsistent categorical values
- converting price and service-fee fields to numeric values
- checking potential outliers
- analysing neighbourhood and room-type distributions
- comparing pricing patterns
- analysing cancellation policies
- examining minimum-night and availability patterns
- creating exploratory visualizations

## Libraries

The analysis uses:

- Pandas
- NumPy
- Matplotlib
- Seaborn

For a notebook-oriented version of the analysis, see:

`../notebooks/nyc_airbnb_eda.ipynb`
