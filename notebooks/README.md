# Jupyter Notebook

This folder contains the notebook version of the NYC Airbnb exploratory data analysis.

## Main Notebook

`nyc_airbnb_eda.ipynb`

The notebook presents the analysis workflow from initial data inspection through cleaning and exploratory visualization.

## Analysis Sections

The notebook includes:

- dataset inspection and descriptive statistics
- column-name standardization
- duplicate detection and removal
- missing-value analysis and imputation
- categorical-data corrections
- price and service-fee cleaning
- minimum-night value correction
- potential outlier detection
- host identity verification analysis
- neighbourhood-group analysis
- room-type and pricing analysis
- cancellation-policy analysis
- construction-year exploration
- price versus service-fee analysis
- minimum-night and availability analysis

## Libraries

- Pandas
- NumPy
- Matplotlib
- Seaborn

The notebook is intended to provide a readable, step-by-step representation of the exploratory data-analysis workflow.
