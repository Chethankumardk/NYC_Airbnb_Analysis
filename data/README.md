# Dataset

This project analyzes the New York City Airbnb Open Data dataset.

## Dataset Source

The original project references the following Kaggle dataset:

**Airbnb Open Data — Kaggle**  
`https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata`

The raw dataset is not redistributed in this repository. Download it from the original source before running the analysis.
